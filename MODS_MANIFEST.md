## Dependencias candidatas condicionales mencionadas

No son mods RPG aprobados ni instalación recomendada por sí mismos; versiones/autores/licencias exactas de artefactos deben verificarse en manifiesto. La auditoría cita Spell Engine, Pufferfish’s Skills, Spell Power Attributes, Cloth Config API, oωo, Fabric API, Ranged Weapon API, Fabric Language Kotlin, Trinkets, Stamina Attributes, Food Overhaul, UnionLib, GeckoLib, JAuml, FTB Library, FTB Teams, Architectury API y Cardinal Components API. No se fija una versión para las que no se aportó. El hecho de que aparezcan como dependencias no las convierte en selección aprobada.

## Datos de distribución y calidad pendientes

- Autor: donde la auditoría/enlaces aportados no proporcionan atribución explícita, queda **[SIN VERIFICAR]**; no se inventa.
- Licencia de una ficha no sustituye el texto del archivo exacto. Revisar licencia, avisos, versión/hash y condiciones del canal antes de redistribuir.
- FTB Quests ARR: no redistribuir JAR sin autorización expresa.
- Ninguna versión/build está aprobada, instalada o certificada compatible con el conjunto. Seleccionar un solo árbol, propietario de atributos y sistema de misiones.
- Mediciones: FPS **NO DATA**; frametime **NO DATA**; RAM **NO DATA**; CPU/GPU **NO DATA**; arranque **NO DATA**; carga **NO DATA**; compatibilidad/estabilidad **NO DATA**. No se ejecutaron pruebas en Athlon 5150/Radeon R3/HDD.
