## Dependencias citadas, no aprobadas

Skill Tree/RPG Series: Pufferfish’s Skills `0.16.7+1.20`, Spell Engine y componentes RPG Series; builds emparejadas exactas pendientes. Simply Skills cita Pufferfish’s Skills, Spell Engine, Spell Power Attributes, Cloth Config API. RPG Inventory cita Trinkets/Cloth Config API. Reforged cita UnionLib. Remnants cita GeckoLib, JAuML y Fabric API. Bosses of Mass Destruction cita Cloth Config API, GeckoLib, Fabric Language Kotlin, Fabric API y Cardinal Components API. FTB Quests usa suite FTB Library/Teams. Mebahel cita Mebahel’s API `1.1.5+`. Verificar las versiones concretas del artefacto antes de uso. No convertir dependencias mencionadas en selección aprobada.
