# Contexto del proyecto

## Modo autónomo

El usuario aprobó todo y delegó todas las decisiones al equipo. No quiere cuestionarios ni conocer el contenido del modpack; el equipo debe tomar las decisiones necesarias, preservar las sorpresas narrativas y entregar el paquete para que el usuario lo descubra jugando. La autonomía no autoriza inventar datos de compatibilidad, dependencias, licencias ni resultados de pruebas, ni subir, retirar, sustituir, modificar o redistribuir archivos de mods de terceros.

## Hardware declarado por el usuario

El usuario actualizó los datos: 12 GB de RAM instalados, unos 10 GB disponibles y Windows usa unos 500 MB. Es una declaración del usuario, no una medición o verificación independiente. Sistema operativo, configuración completa, RAM física total y benchmarks siguen sin verificación.

## Entrega de modpack

La Marea de los Mil Soles usa Minecraft 1.20.1 y Fabric Loader 0.20.1. El manifiesto queda acotado a Sodium y BadOptimizations, mods cliente cuyos IDs/versiones, compatibilidad y plataforma Fabric se indican en los hallazgos recibidos. No se configura servidor. Los candidatos no auditados siguen excluidos, sin asumir incompatibilidad.

La configuración de opciones de Minecraft es una propuesta razonada, no una medición de rendimiento. No se agregan configuraciones de mods que no estén verificadas. Para la memoria, se conserva el criterio prudente: sin argumentos JVM nuevos hasta probar localmente. El valor condicional de `-Xmx5G` solo sería una referencia bajo los datos declarados, no una recomendación medida.

## Mods propios y pruebas

No se recibió código de mods propios ni autorización de implementación; no se crean módulos ni se inventa contenido. No se afirma compilación, arranque, prueba en juego o benchmark. Las consultas incompletas sobre los candidatos se registran como pendientes, indicando que las fuentes consultadas no proporcionaron verificación suficiente.
